# Image Studio API Reference Documentation

> High-performance visual card, leaderboard, profile banner, and animation generator engine powered by Satori, Sharp, and Express.

---

## 🚀 Base URL & Server Endpoints

| Method | Endpoint | Description | Response Content-Type |
|---|---|---|---|
| `POST` | `/api/generate` | **Universal Rendering Endpoint** for Song, Profile, Leaderboard, Quote cards & Animations | `image/png`, `image/gif`, `image/webp` |
| `ALL` | `/api/animation/frame` | **Single Frame PNG Extraction** from Animation Timeline (GET or POST) | `image/png` |
| `GET` | `/api/stats` | **Server Statistics** counter (total generated images count) | `application/json` |

---

## 📡 HTTP Headers

### Request Headers
- `Content-Type: application/json`
- `Accept: image/png` (for static cards) or `image/gif` / `image/webp` (for animations)

### Response Headers
- `Content-Type`: `image/png`, `image/gif`, or `image/webp`
- `X-Total-Generated`: Cumulative count of images/animations generated by the server.
- `X-Image-Height`: Actual pixel height of the rendered output image.
- `Content-Disposition`: `attachment; filename="<safe-filename>"`

## 1. 🎵 Song Search Card API

Generates dynamic 1130px social cards for track search results, playlists, and music bot queries (supports 1 to 20 tracks).

- **Payload Type**: `"song"`
- **Width**: `1130px`
- **Height**: Dynamically calculated based on layout and track count.

### Supported Layouts (`layout`):
- `"auto"`: Automatically selects the best layout based on track count (Default).
- `"list"`: 16:9 widescreen thumbnails with duration, view count, and clean track typography.
- `"grid"`: 2-column square card grid with hover play badge.
- `"classic"`: Compact Discord table row format with circular avatars.

### JSON Payload Schema
```json
{
  "type": "song",
  "title": "Top Trending Hits 2026",
  "layout": "list",
  "items": [
    {
      "index": 1,
      "displayName": "Blinding Lights",
      "author": "The Weeknd",
      "time": "3:20",
      "views": "4.2B views",
      "source": "youtube",
      "avatar": "https://images.unsplash.com/photo-1511671782779-c97d3d27a1d4?w=200"
    },
    {
      "index": 2,
      "displayName": "Starboy",
      "author": "The Weeknd ft. Daft Punk",
      "time": "3:50",
      "views": "2.8B views",
      "source": "spotify",
      "avatar": "https://images.unsplash.com/photo-1470225620780-dba8ba36b745?w=200"
    }
  ]
}
```

### cURL Example
```bash
curl -X POST http://localhost:3000/api/generate \
  -H "Content-Type: application/json" \
  -d '{
    "type": "song",
    "title": "Top Trending Tracks",
    "layout": "list",
    "items": [
      {
        "index": 1,

        "views": "4.2B views",
        "source": "youtube",
        "avatar": "https://images.unsplash.com/photo-1511671782779-c97d3d27a1d4?w=200"
      }
    ]
  }' \
  --output songs.png
```

## 5. 🎬 Animation & Single Frame API

### A) Extract Single PNG Frame via GET (Zero-Configuration)
Directly extract any static frame from an animation timeline preset with query parameters:
```bash
GET /api/animation/frame?preset=welcome&time=350&userName=Alex&guildName=Legends
```

### B) Extract Single PNG Frame via POST (Custom Canvas)
```bash
curl -X POST "http://localhost:3000/api/animation/frame?time=350" \
  -H "Content-Type: application/json" \
  -d '{
    "canvas": {
      "title": "Welcome",
      "width": 930,
      "height": 280,
      "background": "#090614",
      "elements": []
    },
    "tracks": [],
    "templateVariables": {
      "userName": "Alex",
      "guildName": "Legends"
    }
  }' \
  --output frame-350ms.png
```

### C) Render Full GIF / WebP Animation
```bash
curl -X POST http://localhost:3000/api/generate \
  -H "Content-Type: application/json" \
  -H "Accept: image/gif" \
  -d '{
    "type": "animated",
    "data": {
      "title": "Welcome Animation",
      "format": "gif",
      "loop": 0,
      "delay": 100,
      "canvas": { "width": 930, "height": 280, "background": "#090614", "elements": [] },
      "tracks": []
    }
  }' \
  --output welcome.gif
```

## 🤖 Discord Bot Integration Code Examples

### Python (`discord.py`)
```python
import io
import aiohttp
import discord
from discord.ext import commands

bot = commands.Bot(command_prefix="!")
API_URL = "http://localhost:3000/api/generate"

@bot.command()
async def rank(ctx, member: discord.Member = None):
    member = member or ctx.author
    payload = {
        "type": "profile",
        "data": {
            "username": member.display_name,
            "rank": "#1",
            "level": 42,
            "currentXp": 8500,
            "requiredXp": 10000,
            "balance": "15,000 xu",
            "badge": "VIP MEMBER",
            "avatar": member.display_avatar.url,
            "theme": "cyber-neon"  # ruby-poly | cyber-neon | glass-minimal | gold-legend
        }
    }

    async with aiohttp.ClientSession() as session:
        async with session.post(API_URL, json=payload) as resp:
            if resp.status == 200:
                data = await resp.read()
                file = discord.File(io.BytesIO(data), filename="rank.png")
                await ctx.send(file=file)
            else:
                await ctx.send("Failed to render rank card.")

@bot.event
async def on_member_join(member):
    channel = member.guild.system_channel
    if not channel:
        return
    url = f"http://localhost:3000/api/animation/frame?preset=welcome&time=400&userName={member.name}&guildName={member.guild.name}&userAVTurl={member.display_avatar.url}"
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as resp:
            if resp.status == 200:
                file = discord.File(io.BytesIO(await resp.read()), filename="welcome.png")
                await channel.send(f"Welcome {member.mention}!", file=file)
```

### Node.js (`discord.js`)
```javascript
const { Client, GatewayIntentBits, AttachmentBuilder } = require('discord.js');
const client = new Client({ intents: [GatewayIntentBits.Guilds, GatewayIntentBits.GuildMessages] });

client.on('messageCreate', async (message) => {
  if (message.content === '!rank') {
    const payload = {
      type: "profile",
      data: {
        username: message.author.username,
        rank: "#1",
        level: 42,
        currentXp: 8500,
        requiredXp: 10000,
        balance: "15,000 xu",
        avatar: message.author.displayAvatarURL({ extension: 'png' }),
        theme: "gold-legend"
      }
    };

    const response = await fetch("http://localhost:3000/api/generate", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload)
    });

    const buffer = await response.arrayBuffer();
    const attachment = new AttachmentBuilder(Buffer.from(buffer), { name: 'rank.png' });
    await message.channel.send({ files: [attachment] });
  }
});
```
